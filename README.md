# Lab 10 - Navigation Drawer et Fragments

## Description
Ce projet Android Java montre l’utilisation d’un Navigation Drawer pour naviguer entre plusieurs fragments dans une seule activité.

## Fonctionnalités
- Menu latéral personnalisé
- Fragment d’accueil personnalisé
- Deuxième fragment avec une autre interface
- Fragment liste avec plusieurs éléments
- Changement dynamique des fragments avec `FragmentManager`

## Technologies utilisées
- Android Studio
- Java
- XML
- Navigation Drawer
- Fragments
